# Сайт Ольги Соколової

Статичний сайт для GitHub Pages.

## Структура
- `index.html` — контент і структура сторінки
- `style.css` — дизайн та адаптивність
- `script.js` — невеликий JavaScript
- `assets/olha-profile.png` — фото профілю

## Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub, наприклад `olha-sokolova-site`.
2. Завантажте в нього всі файли та папку `assets`.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** виберіть:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Натисніть Save.
6. GitHub покаже адресу сайту.

Після публікації зміни в `index.html`, `style.css` або `script.js` автоматично оновлюватимуть сайт.

## Що можна змінювати без програмування
У `index.html` легко редагуються:
- тексти;
- ціни;
- посилання;
- FAQ;
- блоки послуг.

У `style.css` змінюються кольори, шрифти, відступи та інші елементи дизайну.

## Важливо
Перед публікацією перевірте актуальність цін, посилання на запис/оплату, контактів та юридичних документів.
